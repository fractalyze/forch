# forch v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `Poly` you just multiply (NTT inserted automatically, compiled through the `ntt` opcode), a handwritten CUDA NTT as the speed reference, and one RTX 5090 table comparing them — plus a gap analysis drafted as xla/lattice-frx issues.

**Architecture:** Pure-Python package wrapping `lattice_frx.ring.RnsRing` (opcode path, product); a standalone `nvcc` binary under `benchmarks/handwritten/` implementing the FHE-literature NTT (Shoup + Harvey lazy + ψ^brev tables, 2⁸×2⁸ two-phase, warp-per-256-pt) validated against golden vectors dumped from `HostRnsRing`; a bench script timing both worlds.

**Tech Stack:** Python 3.11, frx (JAX fork) + frx-cuda12-plugin, lattice-frx, zk-dtypes, absl-py tests; CUDA 12.9 `nvcc -arch=sm_120`, no other C++ deps.

**Spec:** `docs/superpowers/specs/2026-08-21-forch-ntt-design.md`

## Global Constraints

- Ring: `Z_q[X]/(X^d + 1)`, benchmark fixed at `d = 2^16`; every limb `q < 2^60`, `q ≡ 1 (mod 2^17)`.
- Byte-exactness: every result must equal `HostRnsRing` (lattigo order) exactly; ψ derives from `lattice_frx.roots.primitive_root` — never an independent root search.
- No FFI, no custom calls, no xla source dependency; the handwritten binary links only CUDA runtime.
- Tests are `absl.testing` (`absltest` + `parameterized`), each file with an `absltest.main()` guard (same convention as lattice-frx).
- Commits: semantic prefixes, no `Co-Authored-By` trailer, atomic, every commit green.
- Python deps only from PyPI + `https://fractalyze.github.io/pypi/simple/` (frx/lattice-frx wheels).
- GPU may be occupied by sibling sessions (32 GB card): run GPU steps with `XLA_PYTHON_CLIENT_PREALLOCATE=false`, and if CUDA init fails check `nvidia-smi` for VRAM before diagnosing anything else.
- Bench methodology: warm, ≥30 reps, `block_until_ready` on a leaf array (a `Poly`/`Eval` is a pytree — call it on `.limbs[0]`).

```python
"""Poly: multiplication and addition insert their own transforms.

Oracle is HostRnsRing: exact integers, lattigo order. The naive O(d^2)
negacyclic product at small d keeps the oracle itself honest.
"""
import numpy as np
from absl.testing import absltest, parameterized

import forch
from lattice_frx.host_ring import HostRnsRing

# 60-bit and 50-bit are the OpenFHE-default shapes; 58/42 (HEaaN FGb shape)
# join in Task 8's bench. Small d keeps the host oracle fast; the GPU bench
# is where d = 2^16 lives.
Q60 = 1152921504606584833          # LastPrime(60, 2^17): also ≡ 1 mod 2*64
Q50 = 1125899903827969
D = 64


def naive_negacyclic(a, b, q, d):
    out = [0] * d
    for i, ai in enumerate(a):
        for j, bj in enumerate(b):
            k = i + j
            v = ai * bj
            if k >= d:
                out[k - d] = (out[k - d] - v) % q
            else:
                out[k] = (out[k] + v) % q
    return out


class PolyTest(parameterized.TestCase):
    def setUp(self):
        super().setUp()
        self.qs = (Q60, Q50)
        self.ring = forch.Ring(self.qs, D)
        self.host = HostRnsRing(self.qs, D)
        self.rng = np.random.default_rng(7)

    def rand(self):
        return np.stack([self.rng.integers(0, q, D, dtype=np.uint64) for q in self.qs])

    def test_mul_matches_host_ntt_product(self):
        a, b = self.rand(), self.rand()
        got = (self.ring.poly(a) * self.ring.poly(b)).coeffs()
        want = self.host.intt(self.host.mul(self.host.ntt(a), self.host.ntt(b)))
        np.testing.assert_array_equal(got, want)

    def test_mul_matches_naive_negacyclic(self):

        got = (self.ring.poly(a) * self.ring.poly(b)).coeffs()
        for li, q in enumerate(self.qs):

        np.testing.assert_array_equal((self.ring.poly(a) + self.ring.poly(b)).coeffs(),

        got = (self.ring.poly(a) * self.ring.poly(b) + self.ring.poly(c)).coeffs()
```

```python
"""forch — FHE evaluation on the lattice-frx substrate.

The one idea in v0: user code multiplies polynomials; the transforms are
inserted here, at trace time, and the whole expression compiles through the
`ntt` opcode. Domain bookkeeping is Python-side state on `Poly` — consistent
with lattice-frx's "the domain is a type": forch only chooses which
statically-typed op to emit, it never branches on a traced value.
"""
from __future__ import annotations

from typing import Optional, Sequence

import numpy as np
from lattice_frx import ring as _ring

__version__ = "0.0.1"
__all__ = ["Ring", "Poly"]


class Ring:
    """`Z_q[X]/(X^d + 1)` over an RNS chain, with an auto-transforming Poly."""

    def __init__(self, q_moduli: Sequence[int], d: int) -> None:
        self._ring = _ring.RnsRing(q_moduli, d)
        self.q_moduli = self._ring.q_moduli
        self.d = d

    def poly(self, arr: np.ndarray) -> "Poly":
        return Poly(self, coeff=self._ring.coeff_from_host(arr))

    def from_signed(self, values) -> "Poly":
        return Poly(self, coeff=self._ring.from_signed(values))


class Poly:
    """A ring element that caches both domains and converts lazily.

    `_coeff` / `_eval` hold the lattice-frx containers; at least one is set.
    Conversions cache: a Poly used twice transforms once per trace.
    """

    def __init__(self, ring: Ring, *, coeff=None, eval_=None) -> None:
        if coeff is None and eval_ is None:
            raise ValueError("Poly needs at least one domain")
        self.ring = ring
        self._coeff: Optional[_ring.Coeff] = coeff
        self._eval: Optional[_ring.Eval] = eval_

    # -- domain access (cached) ------------------------------------------
    def _as_coeff(self) -> _ring.Coeff:
        if self._coeff is None:
            self._coeff = self.ring._ring.intt(self._eval)
        return self._coeff

    def _as_eval(self) -> _ring.Eval:
        if self._eval is None:
            self._eval = self.ring._ring.ntt(self._coeff)
        return self._eval

    def ntt(self) -> "Poly":
        self._as_eval()
        return self

    def intt(self) -> "Poly":
        self._as_coeff()
        return self

    # -- arithmetic ------------------------------------------------------
    def __mul__(self, other: "Poly") -> "Poly":
        self._same_ring(other)
        return Poly(self.ring, eval_=self.ring._ring.mul(self._as_eval(), other._as_eval()))

    def mul_add(self, other: "Poly", acc: "Poly") -> "Poly":
        self._same_ring(other), self._same_ring(acc)
        return Poly(self.ring, eval_=self.ring._ring.mul_add(
            self._as_eval(), other._as_eval(), acc._as_eval()))

    def _addsub(self, other: "Poly", op) -> "Poly":
        self._same_ring(other)
        # Meet in a domain both sides already have; a shared one costs no
        # transform. Otherwise converge on Eval (either choice inserts one
        # transform; Eval is the domain the next mul wants).
        if self._coeff is not None and other._coeff is not None:
            return Poly(self.ring, coeff=op(self._coeff, other._coeff))
        return Poly(self.ring, eval_=op(self._as_eval(), other._as_eval()))

    def __add__(self, other: "Poly") -> "Poly":
        return self._addsub(other, self.ring._ring.add)

    def __sub__(self, other: "Poly") -> "Poly":
        return self._addsub(other, self.ring._ring.sub)

    # -- host boundary ---------------------------------------------------
    def coeffs(self) -> np.ndarray:
        return self.ring._ring.to_host(self._as_coeff())

    def _same_ring(self, other: "Poly") -> None:
        if other.ring is not self.ring:
            raise ValueError("Polys belong to different rings")
```

### Task 4: The two-phase split, pinned in pure Python (forward AND inverse)

**Files:**

**Interfaces:**
- Produces: the exact twiddle-indexing rules the CUDA kernel implements:

  - forward phase 2 (chunks `c`): 256-pt CT-DIT, twiddle `T[m*(256+c) + i]`
  - inverse phase 1 (chunks `c`): 256-pt GS-DIF, twiddle `Tinv[m*(256+c) + i]`

```python
# forch/testing/split_test.py
"""The 2^8 x 2^8 split is twist-free with the psi^brev table.

This is the algebra the handwritten CUDA kernel implements; pinning it here
keeps kernel debugging about memory, not math. Pure CPU, exact ints.
"""
import numpy as np
from absl.testing import absltest

from lattice_frx.host_ring import HostRnsRing
from lattice_frx.roots import bit_reverse, prime_factors, primitive_root

Q = 1152921504606584833
N, LOGN, R = 1 << 16, 16, 256


def tables(q):
    g = primitive_root(q, prime_factors(q - 1))
    psi = pow(g, (q - 1) // (2 * N), q)
    psi_inv = pow(psi, q - 2, q)
    t, tinv = [0] * N, [0] * N
    for i in range(N):
        t[bit_reverse(i, LOGN)] = pow(psi, i, q)
        tinv[bit_reverse(i, LOGN)] = pow(psi_inv, i, q)
    return t, tinv


def ct256(a, tw, q):
    m, t = 1, R
    while m < R:
        t //= 2
        for i in range(m):
            w = tw(m, i)
            for j in range(i * 2 * t, i * 2 * t + t):
                u, v = a[j], a[j + t] * w % q
                a[j], a[j + t] = (u + v) % q, (u - v) % q
        m *= 2
    return a


def gs256(a, tw, q):
    m, t = R // 2, 1
    while m >= 1:
        for i in range(m):
            w = tw(m, i)
            for j in range(i * 2 * t, i * 2 * t + t):
                u, v = a[j], a[j + t]
                a[j], a[j + t] = (u + v) % q, (u - v) * w % q
        m //= 2
        t *= 2
    return a


class SplitTest(absltest.TestCase):
    def setUp(self):
        super().setUp()
        self.host = HostRnsRing([Q], N)
        self.t, self.tinv = tables(Q)
        rng = np.random.default_rng(0)
        self.x = rng.integers(0, Q, N, dtype=np.uint64)

    def test_forward_split(self):
        y = [int(v) for v in self.x]
        for j in range(R):
            col = ct256([y[j + R * k] for k in range(R)], lambda m, i: self.t[m + i], Q)
            for k in range(R):
                y[j + R * k] = col[k]
        for c in range(R):
            y[R * c:R * c + R] = ct256(y[R * c:R * c + R],
                                       lambda m, i, c=c: self.t[m * (R + c) + i], Q)
        want = self.host.ntt(self.x[None, :])[0]
        self.assertEqual(y, [int(v) for v in want])

    def test_inverse_split_roundtrips(self):
        fwd = self.host.ntt(self.x[None, :])[0]
        y = [int(v) for v in fwd]
        for c in range(R):
            y[R * c:R * c + R] = gs256(y[R * c:R * c + R],
                                       lambda m, i, c=c: self.tinv[m * (R + c) + i], Q)
        for j in range(R):
            col = gs256([y[j + R * k] for k in range(R)], lambda m, i: self.tinv[m + i], Q)
            for k in range(R):
                y[j + R * k] = col[k]
        n_inv = pow(N, Q - 2, Q)
        y = [v * n_inv % Q for v in y]
        want = self.host.intt(fwd[None, :])[0]
        self.assertEqual(y, [int(v) for v in want])
        self.assertEqual(y, [int(v) for v in self.x])


if __name__ == "__main__":
    absltest.main()
```

```python
#!/usr/bin/env python3
"""Dump golden NTT vectors + twiddle tables for the handwritten harness.

Everything derives from lattice-frx (generator walk, host ring), so the
binary's byte-exact gate is against the same oracle as the Python suite.
"""
import argparse
import pathlib

import numpy as np
from lattice_frx.host_ring import HostRnsRing
from lattice_frx.roots import bit_reverse, prime_factors, primitive_root

CASES = {  # name: (q, bits)  — OpenFHE-default and HEaaN-FGb shapes
    "q60": 1152921504606584833,   # LastPrime(60, 2^17)
    "q50": 1125899908022273,      # FirstPrime(50, 2^17)
    "q58": 288230376151482369,    # LastPrime(58, 2^17) — verify: (q-1) % 2**17 == 0 and prime
    "q42": 4398045462529,         # LastPrime(42, 2^17) — verify likewise
}


def shoup(w: int, q: int) -> int:
    return (w << 64) // q


def dump(out: pathlib.Path, q: int, d: int, batch: int, seed: int) -> None:
    logn = d.bit_length() - 1
    g = primitive_root(q, prime_factors(q - 1))
    psi = pow(g, (q - 1) // (2 * d), q)
    psi_inv = pow(psi, q - 2, q)
    t, tinv = [0] * d, [0] * d
    for i in range(d):
        t[bit_reverse(i, logn)] = pow(psi, i, q)
```

### Task 6: Handwritten forward NTT (the reference kernel)

**Files:**

**Interfaces:**

- [ ] **Step 1: Write the kernel.** Full file; the warp routine is shared by both phases (twiddle indexing differs by a base multiplier: phase 1 `base=1, off=0` → `T[m+i]`; phase 2 `base=(256+c)` → `T[m*(256+c)+i]`):

```cuda
// ntt.cu — negacyclic forward NTT, 2^16 = 2^8 x 2^8, the FHE-literature design:
// Shoup multiply + Harvey lazy [0,4q) (Harvey JSC'14; Longa–Naehrig CANS'16),
// psi^brev tables (twist merged, output natively bit-reversed = lattigo order),
// one warp per 256-pt sub-transform, 8 elements per lane:
//   3 in-register stages (t=128,64,32: partner is another register)
// + 5 shuffle stages    (t=16..1:     partner is another lane).
#include <cstdint>
#include <cuda_runtime.h>

using u64 = unsigned long long;

struct Tables { const u64 *t, *t_shoup; u64 q, n_inv, n_inv_shoup; };

__device__ __forceinline__ u64 mul_shoup(u64 x, u64 w, u64 ws, u64 q) {
  return x * w - __umul64hi(x, ws) * q;                    // any x, out in [0, 2q)
}

// CT butterfly, both elements in registers. x,y in [0,4q) -> [0,4q).
__device__ __forceinline__ void ct_reg(u64 &x, u64 &y, u64 w, u64 ws, u64 q, u64 two_q) {
  if (x >= two_q) x -= two_q;
  u64 t = mul_shoup(y, w, ws, q);
  y = x - t + two_q;
  x = x + t;
}

// One 256-pt CT-DIT in a warp. v[8]: lane l owns elements {l + 32r}.
// tw index for stage m, group i is (m*base + i); base=1 for phase 1,
// base=256+c for phase 2 (the twist-free split, forch split_test.py).
__device__ __forceinline__ void ntt256_warp(u64 v[8], const Tables tb, u64 base) {
  const u64 q = tb.q, two_q = 2 * tb.q;
  const unsigned lane = threadIdx.x & 31u;
  // Register stages: t = 128, 64, 32  <=> partner r ^ {4,2,1}.
  for (int s = 0; s < 3; ++s) {
    const unsigned m = 1u << s, t = 128u >> s, rmask = 4u >> s;
    for (unsigned r = 0; r < 8; ++r) {
      if (r & rmask) continue;                       // visit each pair once
      const unsigned e = lane + 32u * r;             // x element's index
      const unsigned i = e / (2u * t);
      const u64 idx = (u64)m * base + i;
      ct_reg(v[r], v[r | rmask], tb.t[idx], tb.t_shoup[idx], q, two_q);
    }
    // groups per stage double; e/(2t) uses x's index — for r without the bit, ok.
  }
  // Shuffle stages: t = 16, 8, 4, 2, 1 <=> partner lane ^ t.
  for (int s = 3; s < 8; ++s) {
    const unsigned m = 1u << s, t = 128u >> s;       // t = 16..1
    for (unsigned r = 0; r < 8; ++r) {
      const unsigned e = lane + 32u * r;
      const unsigned i = e / (2u * t);
      const u64 idx = (u64)m * base + i;
      const bool hi = (lane & t) != 0;               // role: hi lane holds y
      u64 send;
      if (hi) send = mul_shoup(v[r], tb.t[idx], tb.t_shoup[idx], q);  // t-value
      else { if (v[r] >= two_q) v[r] -= two_q; send = v[r]; }          // reduced x
      const u64 got = __shfl_xor_sync(0xffffffffu, send, t);
      v[r] = hi ? got - send + two_q          // wait: hi needs x - t; got = x, send = t
                : v[r] + got;                 // lo: x + t
    }
    __syncwarp();
  }
}

// Final reduction [0,4q) -> [0,q).
__device__ __forceinline__ u64 reduce4q(u64 x, u64 q, u64 two_q) {
  if (x >= two_q) x -= two_q;
  if (x >= q) x -= q;
  return x;
}

#ifndef T_COLS
#define T_COLS 16
#endif

// Phase 1: columns. Block = T_COLS warps; tile [256][T_COLS] staged via smem
// (padded row to dodge 64-bit bank conflicts). Grid.x = 256/T_COLS, grid.y = batch.
__global__ void fwd_phase1(u64 *data, Tables tb) {
  __shared__ u64 sh[256][T_COLS + 1];
  u64 *poly = data + (u64)blockIdx.y * 65536u;
  const unsigned j0 = blockIdx.x * T_COLS;
  const unsigned nthr = T_COLS * 32u;
  // Coalesced tile load: consecutive tid -> consecutive j, then k.
  for (unsigned e = threadIdx.x; e < 256u * T_COLS; e += nthr)
    sh[e / T_COLS][e % T_COLS] = poly[(u64)(e / T_COLS) * 256u + j0 + (e % T_COLS)];
  __syncthreads();
  const unsigned w = threadIdx.x >> 5, lane = threadIdx.x & 31u;
  u64 v[8];
  for (unsigned r = 0; r < 8; ++r) v[r] = sh[lane + 32u * r][w];
  ntt256_warp(v, tb, /*base=*/1u);
  for (unsigned r = 0; r < 8; ++r) sh[lane + 32u * r][w] = v[r];
  __syncthreads();
  for (unsigned e = threadIdx.x; e < 256u * T_COLS; e += nthr)
    poly[(u64)(e / T_COLS) * 256u + j0 + (e % T_COLS)] = sh[e / T_COLS][e % T_COLS];
}

#ifndef W_CHUNKS
#define W_CHUNKS 8
#endif

// Phase 2: contiguous chunks, no smem, no block sync. Block = W_CHUNKS warps,
// warp w owns chunk c = blockIdx.x*W_CHUNKS + w. Reduces to [0,q) on store.
__global__ void fwd_phase2(u64 *data, Tables tb) {
  u64 *poly = data + (u64)blockIdx.y * 65536u;
  const unsigned w = threadIdx.x >> 5, lane = threadIdx.x & 31u;
  const unsigned c = blockIdx.x * W_CHUNKS + w;
  u64 *chunk = poly + (u64)c * 256u;
  u64 v[8];
  for (unsigned r = 0; r < 8; ++r) v[r] = chunk[lane + 32u * r];
  ntt256_warp(v, tb, /*base=*/256u + c);
  const u64 two_q = 2 * tb.q;
  for (unsigned r = 0; r < 8; ++r) chunk[lane + 32u * r] = reduce4q(v[r], tb.q, two_q);
}

extern "C" void run_forward(u64 *d_data, const Tables *tb, int batch, cudaStream_t s) {
  dim3 g1(256 / T_COLS, batch), g2(256 / W_CHUNKS, batch);
  fwd_phase1<<<g1, T_COLS * 32, 0, s>>>(d_data, *tb);
  fwd_phase2<<<g2, W_CHUNKS * 32, 0, s>>>(d_data, *tb);
}
```

**Known thin ice to verify while making it pass (in this order):**
1. The shuffle-stage role algebra (the `hi ? got - send + two_q : v[r] + got` line): the hi lane's new value is `x - t + 2q`; `got` is the partner's reduced `x`, `send` is its own `t` — so it must be `got - send + two_q`. Walk one length-4 example on paper before first compile.
2. Register-stage group index `i = e/(2t)` must use the **x element's** `e` (the one without the `rmask` bit) — it does, because the loop skips `r` with the bit set.
3. Shuffle stages need every lane's element pair to agree on `i`: `e/(2t)` with `t ≤ 16` differs only in bits ≥ 5 iff pairs share it — pairs differ in bit log2(t) < 5, and `2t ≤ 32` divides `e` at bit 5+ ... verify with an assert-under-`-G` build or a printf spot-check at N=256, batch=1.
4. `-Xptxas -v` register count: if > 96 or spills appear, drop to 4 elements/lane (`v[4]`, 2 register stages + 6 shuffle... adjust masks accordingly) — record the decision in the README.

```cuda
__device__ __forceinline__ void gs_reg(u64 &x, u64 &y, u64 w, u64 ws, u64 q, u64 two_q) {
```
